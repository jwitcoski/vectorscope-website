## One-line pitch

**Vector Scope AI delivers the missing lakehouse layer for ArcGIS:** collaborative editing on Apache Iceberg and GeoParquet, with containerized GIS (QGIS/ArcGIS Pro), so Spark/Sedona data lakes work with ArcGIS Online.

---

## Product: Vector Ledger

- **What it is:** A platform where all map edits are recorded and versioned in one ledger—whether from Esri web apps, cloud QGIS, or cloud ArcGIS Pro. Output is versioned GeoParquet (and Iceberg when adopted).
- **Who it’s for:** Agencies and organizations that already have (or want) Spark/Sedona/Iceberg data lakes and need collaborative editing and clean GeoParquet for ArcGIS.
- **How it uses ArcGIS:** Esri web apps and ArcGIS Online/Enterprise for editing and publishing; Vector Ledger adds the wiki/lakehouse layer so Iceberg/GeoParquet tables become editable and stay in sync with ArcGIS.

---

## Why now / market gap

- **No major Esri partner** is publicly running Apache Sedona, Iceberg, or Spark as their core geospatial stack in production. It’s mostly community demand and early experimentation.
- **Esri community** has 100+ votes on ideas for Sedona/Iceberg support—clear demand with no Esri-partner solution today.
- **CARTO, Wherobots** and others push Iceberg + GeoParquet as data platforms, but not as “Esri + lakehouse collaboration.” We fill that gap.

- **Live demo:** [globalskiatlas.com](https://globalskiatlas.com)
