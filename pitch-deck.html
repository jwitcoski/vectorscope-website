Collaborative map updates for agencies

Vector Ledger is a hosted app: upload a shapefile, edit on the map, approve the change list, publish GeoParquet and a web map.

The gap we fill

Map data still moves around as email attachments, or it gets locked in a database nobody else can open.

Teams want a shared editor with an approval trail—and a file they can open in QGIS, ArcGIS Pro, or DuckDB.

Vector Ledger is that hosted workflow. Live today at app.vectorscopeai.com.

Vector Ledger

Setup, Editor, Dashboard, Lake

Create a sandbox, upload a shapefile zip, convert to GeoParquet. People edit on the map. Approvers see the change list. Publish GeoParquet, PMTiles, and a MapLibre preview.

Who it’s for: agencies and orgs that need non-GIS staff to update official map data—and still want real files at the end.

Future architecture

Roadmap: tighter ArcGIS sync, Iceberg tables, heavier GIS production. The live product is Setup → Editor → Dashboard → Lake.
